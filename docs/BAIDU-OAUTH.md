# 百度开放平台授权配置

百度开放平台页面名称可能调整，以下以字段含义为准。

1. 登录百度开放平台或百度网盘开放平台。
2. 创建一个供自己使用的应用。
3. 按平台要求启用百度网盘文件读取相关权限。
4. 打开源览的“扩展程序选项”。
5. 复制页面显示的回调地址，格式类似：

   ```text
   https://你的扩展ID.chromiumapp.org/baidu
   ```

6. 将完整地址登记到百度应用的授权回调地址 / Redirect URI。
7. 复制自己的 App Key / API Key，粘贴到源览设置页并保存。
8. 点击“连接百度网盘”完成授权。

回调地址必须逐字一致。不要使用别人的扩展 ID，也不要把 Secret Key 填入扩展。
