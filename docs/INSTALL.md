# 安装说明

## 1. 下载并解压

1. 打开本仓库的 Releases 页面。
2. 下载 `design-peek-v0.1.0.zip`，不要下载 GitHub 自动生成的 Source code ZIP。
3. 解压到一个固定文件夹。
4. 后续不要移动、改名或删除这个文件夹，否则扩展 ID 可能改变。

## 2. 加载到 Chrome

1. Chrome 打开 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择解压后的文件夹；第一层应能看到 `manifest.json`。
5. 打开源览的“详情”，点击“扩展程序选项”。

## 3. 配置并使用

1. 在设置页复制当前扩展 ID 和授权回调地址。
2. 按照 [百度授权配置](BAIDU-OAUTH.md) 创建自己的应用。
3. 只填写自己的 App Key，不要填写 Secret Key。
4. 打开扩展弹窗，点击“连接百度网盘”。
5. 刷新百度网盘网页，点击 PSD 文件旁的“快速预览”。

## 常见问题

- `redirect_uri_mismatch`：百度平台登记的回调地址与设置页显示的地址不一致。
- 没有“快速预览”：确认文件为 `.psd`，刷新百度页面，并检查扩展是否启用。
- 换电脑后不能授权：新安装的扩展 ID 可能不同，需要登记新的回调地址。
